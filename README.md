# teknik-servis-kay-t-formu-denemesi
Ders olarak teknik servis için bir kayıt formu oluşturmayı denemiştim kısa sürede yapılan bir deneme sitesi.

🛠️ Teknik Servis Kayıt Sistemi
Kullanıcıların teknik servis taleplerini hızlıca oluşturabildiği, modern ve kullanıcı dostu bir web arayüzü. Bu proje, temel HTML, CSS ve JavaScript yetkinliklerini sergilemek amacıyla geliştirilmiştir.

🚀 Özellikler
Dinamik Kayıt Yönetimi: Sayfa yenilenmeden JavaScript dizileri ile anlık kayıt ekleme ve listeleme.

Modern Arayüz: CSS Flexbox ve Grid sistemleri kullanılarak tasarlanmış, tamamen duyarlı (responsive) yapı.

Gece/Gündüz Modu: Kullanıcı tercihine göre değiştirilebilen dinamik tema desteği.

Veri Doğrulama: HTML5 form validation ve RegEx ile telefon numarası kontrolü.

Otomatik Tarih: Form açıldığında geliş tarihini güncel tarihe sabitleme özelliği.

🛠️ Kullanılan Teknolojiler
HTML5: Semantik yapı ve form kontrolleri.

CSS3: Özel değişkenler (CSS Variables), geçiş efektleri ve modern layout teknikleri.

JavaScript (ES6+): DOM manipülasyonu, event handling ve veri işleme.
